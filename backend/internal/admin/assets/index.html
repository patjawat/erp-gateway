ใบรับรอง Gateway

ใช้ใบ client เดิมเพื่อรักษาการเชื่อมต่อ หรือสร้าง CSR ให้ CA ลงนาม Private key อยู่ที่ Gateway เท่านั้น

นำ CSR ไปให้ผู้ดูแล CA ลงนาม แล้ววางใบที่ได้รับด้านล่าง ไม่ต้องนำ private key ออกจาก Gateway
วิธีลงนาม CA และนำเข้าใบรับรอง

คุณลงนามเองบน Mac ที่เก็บ CA ได้ คำสั่งด้านล่างใช้ Python 3 และ OpenSSL 3 ขึ้นไป โดยสมมติว่าโครงการอยู่ที่ ~/dev/erp-platform/gateway หากเก็บไว้ที่อื่น ให้แก้พาธสคริปต์ก่อนรัน

  1. เตรียม CSR ของ Gateway เครื่องนี้

    กด “สร้าง CSR ที่ Gateway” คำสั่งด้านล่างจะใช้ CSR ที่แสดงในหน้านี้โดยตรง ไม่ต้องเลือกไฟล์ใน Downloads จึงไม่สับสนกับไฟล์เก่า ยังดาวน์โหลดหรือคัดลอก CSR แยกได้หากต้องส่งให้ผู้ลงนามคนอื่น

  2. สร้าง CA เฉพาะครั้งแรก

    ถ้ามี CA เดิมที่ใช้กับระบบนี้ ให้ข้ามไปขั้นลงนาม ใช้ตำแหน่ง CA เดิม และอย่าสร้าง CA ใหม่แทนเมื่อต่ออายุ

    ตั้งรหัสผ่าน CA ที่ต้องการและยืนยันใน Terminal เก็บรหัสไว้ในโปรแกรมจัดการรหัสผ่าน และสำรอง CA แบบเข้ารหัส

  3. ลงนามและรวม chain ด้วย CA เดิม

    เลือกจำนวนเต็ม 1–365 วัน อายุเริ่มเมื่อสั่งลงนามบน Mac ค่านี้ไม่ต่ออายุใบเดิมและไม่เปลี่ยนอายุ CA

    สร้าง CSR ของ Gateway เครื่องนี้ก่อนคัดลอกคำสั่งลงนาม

    วางคำสั่งทั้งหมดใน Terminal บน Mac แล้วใส่รหัสผ่าน CA จะได้ใบรับรองตามจำนวนวันที่เลือก และค่า HOSPITAL_GATEWAY_CLIENT_SPKI_SHA256 สำหรับตั้งค่าฝั่ง API แต่ละครั้งจะสร้างโฟลเดอร์ใหม่ใน Downloads และแสดงพาธไฟล์ chain ที่ต้องนำกลับเข้าเว็บ

  4. นำ chain ที่เพิ่งสร้างกลับเข้า Gateway

    เลือกไฟล์ gateway-client-chain.pem ตามพาธที่ Terminal แสดง เข้าในช่องใบรับรอง client และ chain เมื่อใช้ CSR ที่ Gateway สร้าง ไม่ต้องใส่ private key เพิ่มเติม เมื่อต่ออายุด้วย CA และกุญแจ Gateway เดิม โดยปกตินำเข้าใบ client ใหม่ที่ Gateway เท่านั้น

Private key ของ Gateway อยู่ที่ Gateway ส่วน gateway-client-ca.key.pem อยู่บน Mac ผู้ลงนาม ไม่อัปโหลดคีย์ CA เข้าเว็บหรือส่งให้หน่วยงาน

ฝั่ง API ต้องเชื่อถือใบ CA สาธารณะ gateway-client-ca.crt.pem และตั้ง SPKI ของ Gateway ด้วย จึงเชื่อมต่อได้ ฝั่ง API เก็บ CA สาธารณะและ SPKI เดิมไว้เมื่อต่ออายุด้วย CA และกุญแจเดิม ส่วนช่อง “CA ของใบ server โรงพยาบาล” ในหน้า Setup ใช้ตรวจตัวตนโรงพยาบาล เป็นคนละส่วนกับ CA ที่ใช้ลงนามนี้

เว้นว่างเมื่อใช้ CSR ที่ Gateway สร้างไว้ ไม่แจก key ของ Gateway ให้หน่วยงานเว้นว่างเมื่อโรงพยาบาลใช้ใบ server จาก CA สาธารณะที่ระบบเชื่อถือ
